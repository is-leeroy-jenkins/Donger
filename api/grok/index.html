    Grok API¶

    Purpose¶

    This page documents the Grok provider class used by Donger.

    Responsibilities¶

    The Grok class is responsible for provider-facing workflows, including text generation, image generation and analysis, image editing, embeddings, audio transcription, audio translation, text-to-speech, Grok Files API operations, file-search stores, and Google Cloud bucket workflows.

    Import Requirements¶

    This API page imports grok.py. Build the documentation from the repository root after installing both application and documentation dependencies:

    pip install -r requirements.txt
mkdocs build --strict
